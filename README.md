# 人形訓練場

《少女前線》同人 2D 俯視射擊網頁遊戲。線上遊玩：https://woo369.github.io/renxingBattle/

## 操作
- 電腦：WASD／方向鍵移動、滑鼠瞄準、左鍵或空白鍵開火、Shift 或右鍵閃避、Q 技能、R 裝彈、滾輪縮放、P／Esc 暫停
- 手機：左下搖桿移動，右下角開火、閃避、技能、裝彈與擴編按鈕

## 內容
- 人形：三重冕、HK433、82式、馬提尼亨利、蜂鳥
- 關卡：訓練場、戰事（第一階段＋精英 Boss 隨機抽選、第二階段）
- 精英敵人：銜尾蛇、夢想家、稻草人

角色素材為《少女前線》官方美術，版權屬原廠，僅供個人與朋友遊玩。
